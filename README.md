# E-Tasmik Daerah - paparan (tapak statik)

Halaman paparan sistem E-Tasmik yang dihos di GitHub Pages. Ia hanya HTML/CSS/JS: log masuk, data dan
logik berada di enjin Google Apps Script (alamat dalam `config.js`). Tiada data murid, kata laluan atau
kod enjin dalam repo ini.

- `index.html` - dijana daripada repo utama (jangan sunting di sini).
- `config.js` - satu baris: alamat web app Google (`.../exec`).

Pautan sekolah: `https://<akaun>.github.io/<repo>/?kod=KODSEKOLAH` (mengisi Kod Sekolah pada borang log masuk).
